    01 The problem

    A plastic credit is worth $140–800 per tonne. That is a direct financial incentive to invent a weigh-in that never happened.

    Most waste-credit systems answer this with a spreadsheet and a promise. ProofChain answers it with evidence a buyer can recompute on their own machine.

    02 Weigh-in to audit report

      Six steps, and the evidence hardens at every one.

      Follow a single weigh-in through the system. The panel on the right shows what the record actually looks like at that moment — payload, verdict, root, transaction.

      03 Integrity v1

      Seven checks, each named for the attack it stops.

      A fail quarantines the event permanently; it can never enter a batch. A warn is recorded but does not block.

      04 Don't trust us

      Verify a batch on your own machine.

      The audit report is public and needs no authentication. Everything below runs with curl, jq and node against a batch ID you were handed — nothing else.

      Four passes and the tonne stands on its own. Fail any one of them and you should reject the batch — including if we tell you otherwise.

      How the tree is built.

      Three deliberate departures from the naive Merkle tree, plus the ordering that makes the result reproducible — each stated with the attack it stops. Implemented in packages/shared/src/merkle.ts.

      05 Maturity, stated plainly

      What this release proves — and what it does not.

      ProofChain is a testnet pilot build, not a certified credit issuer. A verification system that overstates itself defeats its own purpose, so the boundary is printed here rather than buried in a footnote.

      Shipped in this release

      • ✓

      • —

      • —
        Public network deployment testnet only, pending a security audit
